# 已知限制

## P1：安卓深度休眠与厂商后台限制

后台连接使用前台服务和 Headless JS，可在正常切换应用时保持运行。Android Doze 和厂商省电策略仍可能限制长时间熄屏时的 CPU 或网络；系统强制停止应用也会结束连接。长时间后台运行需要允许系统电池设置中的“不受限制”。不绕过用户省电设置，不为保活伪造音频播放。详见 [安卓后台主机连接](android.md#后台主机连接)。

## P2：远端文件的内置预览类型有限

MP4、压缩包等文件通过下载和外部应用使用。暂不增加通用播放器和文档引擎，优先保证远程资源能够取回。详见 [文件下载](file-downloads.md)。

## P2：网页下载受浏览器内存限制

原生客户端逐块写入文件；网页和桌面网页客户端需要在生成浏览器下载时保留文件内容。超大文件可能受浏览器可用内存限制。跨浏览器的磁盘流式保存还需要单独设计，此次优先解决安卓中继下载。
